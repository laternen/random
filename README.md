# 🏠 РанДом — Симулятор оценки домов в Москве

Интерактивный веб-симулятор, который позволяет угадывать стоимость домов в Москве и области по фото и описанию.

## 🎮 Механика

- Из базы данных (46 реальных объявлений с Cian.ru) выбираются **10 случайных домов**
- Пользователь видит фото, площадь дома, участок и локацию
- С помощью **бегунка** нужно угадать стоимость объекта
- После нажатия «Оценить» показывается правильный ответ и разница
- По итогам 10 раундов определяется титул:
  - 🏆 **Опытный инвестор** — близок к результату (≥70% баллов)
  - 💰 **Щедрый инвестор** — переплачивает за недвижимость (40-69%)
  - 🤏 **Скряга** — экономный инвестор (<40%)

## 📊 Система подсчёта баллов

| Отклонение | Баллы |
|-----------|-------|
| ≤2%       | 100   |
| ≤5%       | 80    |
| ≤10%      | 60    |
| ≤20%      | 40    |
| ≤35%      | 20    |
| ≤50%      | 10    |
| >50%      | 0     |

## 🛠 Технологии

- **React 18** + TypeScript
- **Vite** — сборка
- **Tailwind CSS 4** — стилизация
- Основной цвет: `#26CD94`

## 📱 Особенности

- Мобильная версия в приоритете
- Один экран = одна карточка
- Минимальный трафик
- Логарифмический бегунок (от 3 млн до 8 млрд ₽) для удобной оценки
- Реальные фото домов с Cian.ru
- Анимации и плавные переходы
- Security headers в HTML

## 🌐 Деплой

Проект — статический SPA. После `npm run build` папку `dist/` можно деплоить на любой хостинг:

- **Vercel**: `vercel deploy`
- **Netlify**: перетащить `dist/` в дашборд
- **GitHub Pages**: загрузить `dist/` в ветку `gh-pages`
- **Любой статический хостинг**: загрузить содержимое `dist/`

## 🔒 Безопасность

Реализованы security headers:
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- `Content-Security-Policy` (разрешены только доверенные источники)

## 📋 Данные

В приложении используются реальные данные о домах из таблицы Google Sheets:
- 46 объявлений о продаже домов и коттеджей
- Цены от 4.7 млн до 7.7 млрд ₽
- Площади от 70 м² до 4 700 м²
- Локации: Москва, Новая Москва, Подмосковье
- Фотографии с Cian.ru
